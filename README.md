## 🌐 1-Click Free Deployment Instructions

### Deploy to Vercel (Recommended)
1. Push your repository to GitHub.
2. Visit [vercel.com](https://vercel.com) and click **Add New Project**.
3. Import this repository. The included `vercel.json` will automatically configure all routes.
4. Click **Deploy** — your live URL will be ready in 30 seconds!

### Deploy to Netlify
1. Visit [netlify.com](https://netlify.com) and import your GitHub repository.
2. The included `netlify.toml` will handle build command `npm run build` and output directory `dist`.
3. Click **Deploy Site**.
